# 画面の確かめの手順（毎回同じに通す）

画面のファイルを変えたら、確認用の画面（このフォルダを `http://127.0.0.1:8765/` で配ったもの）で、下の 2 本を上から通す。
報告には「通した項目」と「通せなかった項目（と理由）」を両方並べる。通せなかった項目を黙って省かない。

## 0. 始める前に

- 古い画面が出ないように、サービスワーカーの登録を外し、控え（`mealprep-dish-photos` 以外）を消してから開き直す
- 画面の下の「設定」→ いちばん下の「アプリの版」が、いま直した番号になっているか
- 開発ツールの表示に、守りの設定（CSP）に引っかかった記録と、エラーが 0 件か

## 1. 週を受け取ってから日曜まで

| # | 操作 | 見ること |
|---|---|---|
| 1-1 | ログインした状態で開く（または「設定」で週のファイルを取り込む） | 「献立」に週が出る。週が 2 つ以上なら、上に週の切り替えが出る |
| 1-2 | 「献立」で曜日を切り替え、カードを 1 枚押す | 「食べた」の印が付く。もう一度押すと外れる |
| 1-3 | 「買い物」で 1 行チェックし、「無かった」を 1 つ押す | 下のタブの数字（残り）が 1 減る。「メモ」に「店に無かったもの」が出る |
| 1-4 | 「買い物のチェックを外す」→ 知らせの「元に戻す」 | チェックが全部外れ、「元に戻す」で元に戻る |
| 1-5 | 「料理」→「レシピ」で「できた。次へ」を押す | いまの手順が次へ進む。時間の帯の色が変わる。「くわしい手順を見る」が開ける |
| 1-6 | 「メモ」を開く | 新しい注意があれば、下のタブの点が消える |
| 1-7 | 試しに付けた印を、すべて外して元に戻す | 試しの前と同じ状態 |

## 2. 頼む（本物の注文は置かない）

本物の注文を置くと、見張り役が拾って献立を作り直す。確かめでは、ページの中で `window.fetch` を差し替え、`/rest/v1/requests` への POST には偽の返事（`week_start` と `status: "new"` を入れる）を返す。

| # | 操作 | 見ること |
|---|---|---|
| 2-1 | ログインを外した状態（`localStorage` の `mealprep-session-v1` を一時的に退避）で「献立を頼む」 | ログイン欄まで動き、メール欄に合う。下の 4 つのタブの空の画面は「ログインする」ボタン 1 つ |
| 2-2 | ログインを戻して「今回ほしい分」→「これで決める」→ 品を 1 つ選ぶ | 枠に品が入る。「これで決める」の前に選ぶと知らせが出て止まる |
| 2-3 | 絞り込みで 0 品になる組み合わせを作る | 「条件に合う品はありません」と、外すと何品になるかのボタンが出て、押すと外れる |
| 2-4 | もう献立のある週で「献立を頼む」 | 「作り直す／いまのまま」の確認の画面が出る。「いまのまま」で何も起きない |
| 2-5 | 偽の返事で頼む | 「受け付けた → 組んでいる → 届いた」の段が出て、「受け付けた」が光る。「ほかのタブを使っていて大丈夫」が出る |
| 2-6 | 偽の返事を 409 にして頼む | 「この週の献立は、いま組んでいるところです」が出る |
| 2-7 | 偽の返事を 503 にして頼む | 英語や番号ではなく「少し待ってから、もう一度試してください」と「もう一度試す」が出る |
| 2-8 | 開発ツールで通信を切る（オフライン） | 上に「電波がありません」の印が出る。つなぎ直すと消える |
| 2-9 | ログアウトを押す | 「ログアウトする／やめる」の確認の画面が出る。「やめる」で何も起きない |
| 2-10 | `window.fetch` を元に戻し、退避したログインを戻して開き直す | 試しの前と同じ状態 |

## 確かめられないこと（報告で必ず触れる）

- iPhone の実機での見え方（文字の大きさ・ホーム画面のアプリとしての動き）
- 本物の注文が見張り役で仕上がるまで（頼むのは Yuzo の操作のときに確かめる）
- 冷蔵庫の写真を本物の置き場へ送る動き
