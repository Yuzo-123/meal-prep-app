# 日曜につくりおき（meal-prep-app）

家族用の PWA。1 週間の作り置きの献立・買い物リスト・日曜の段取りとレシピを、スマホで見る・チェックする・頼む。
作業するときの決まりは `CLAUDE.md`。

## できること（版 0.12 系・2026-11-16）

- **何つくる？**: 期間と「1 回に出す品数」（夜・朝の汁物とおかず）を決め、食べたい品を選んで「献立を頼む」。押した瞬間にアプリの中で献立・買い物・日曜の段取り・レシピを組んで出す（`src/js/planner.js`）。冷蔵庫の写真を送っておくと、あとから家にあるものが買い物に反映される
- **献立**: 週の切り替え・曜日ごとの朝と夜・料理の写真・「食べた」の印
- **買い物**: 売り場別・料理で絞る・チェック・「無かった」・残りの数
- **料理**: 作る品・材料・下準備・レシピ（コンロとレンジの全体の流れ、品ごとの詳しい手順、タイマー）
- **メモ**: 気をつけること・今週の記録
- **設定**: 週のファイルの取り込み・表示する週・書き出し（バックアップ）・ログアウト
- 家族 2 人のログインで、週の献立・品の一覧・料理の写真をサーバーから受け取る。電波が無くても、端末の写しで開ける

まだ無いもの: 在庫・食費・生協の注文の取り込み。

## データの置き場

| データ | 置き場 |
|---|---|
| 画面のファイル | このリポジトリ（公開） |
| 週の献立・品の一覧・料理の写真・冷蔵庫の写真・注文 | Supabase の非公開の置き場（家族 2 人だけ。`supabase/*.sql` が決まり） |
| 買い物や料理のチェック・メモの記録 | 端末の中だけ（ログアウトしても消えない。機種変更の前は書き出す） |

### データの約束（2026-11-17）

- **品の番号は使い回さない。** 番号（`r046` など）は、献立・チェック・料理の写真の名前（`dish/<家庭>/<品の番号>.jpg`）をつなぐ鍵。品をやめても、その番号をほかの品に付け直さない
- **データの形には版がある。** 週のデータは `format: "mealprep-week"`・`version: 1`、品の一覧は `format: "mealprep-catalog"`・`version: 1`、書き出しは `format: "mealprep-backup"`・`version: 1`。形を変えるときは `version` を上げ、古い版を読めるようにしてから送る（読めない形が届くと、アプリは「開き直して、新しい版にしてください」と出す）
- 同じ週で進行中の注文は 1 件まで（`supabase/005`）。作り直すときは、アプリが前の手付かずの注文を取り消してから頼む
- 家庭の表・献立の置き場の一本化・退会したときの注文の残し方は、売ると決めたときにまとめて直す（いまは家族 2 人なので困らない）

## 手元で動かす

- テスト: このフォルダで `node --test`
- 画面の確かめ: `test/screen-check.md` の 2 本の流れを、確認用の画面で毎回同じに通す
- コミットの前に `tools/check_version.py` が、画面のファイルを変えたのに版を上げていないコミットを止める
- 確認用のサーバー: このフォルダを静的に配る（例 `python3 -m http.server 8765`）。サービスワーカーが古い画面を出したら、ブラウザの開発ツールで登録を外して控えを消す

## 中身

| 場所 | 役割 |
|---|---|
| `index.html` | 画面の骨組み（守りの設定 CSP は `<meta>` で入れている） |
| `src/js/model.js` | データの形と計算（画面に依らない。テストの対象） |
| `src/js/planner.js` | アプリの中で献立・買い物・段取りを組む（テストの対象） |
| `src/js/cloud.js` | ログイン・サーバーとのやりとり・写真の控え |
| `src/js/store.js` | 端末の中への保存 |
| `src/js/app.js` | 画面の動き |
| `src/css/styles.css` | 見た目 |
| `service-worker.js` `manifest.json` `icons/` | ホーム画面に置く・電波なしで開くための仕掛け |
| `supabase/` | 置き場の表と「誰が読めるか」の決まり（番号順に流す） |
| `tools/export_week.py` `tools/export_catalog.py` | 週のデータ・品の一覧を、取り込める形に書き出す |
| `tools/push_week.py` | 書き出したものを非公開の置き場へ送る |
| `tools/requests.py` `tools/fetch_fridge.py` | 届いた注文を読む・冷蔵庫の写真を取り込む |
| `tools/check_rules.py` | ログインしていない立場で、何も見えないことを試す |
| `tools/check_version.py` | 画面のファイルを変えたのに版を上げていないコミットを止める |
| `tools/set_password.py` | 家族の利用者にパスワードを決める（持ち主がターミナルで実行） |
| `tools/make_icons.py` `tools/make_icon_variants.py` `tools/make_mascot.py` `tools/crop_dish_photos.py` | アイコン・キャラクター・料理の写真づくり |
| `tools/build_preview.py` | 確認用の 1 ページを組み立てる（いまは使っていない） |
| `test/` | テスト（部品の計算）と、画面の確かめの手順（`screen-check.md`） |
